# Community conduct

Treat contributors, users and maintainers with respect. Discuss ideas and evidence
without personal attacks. Harassment, discriminatory language, threats, unwanted
sexual attention, doxxing and publishing another person's private information are
not acceptable in project spaces.

Maintainers may edit or remove harmful content, restrict participation, and explain
their decisions where doing so does not expose private reports. Enforcement should
be consistent and proportionate. Respect confidential reports and requests to stop
unwanted contact.

Report a concern privately to the repository maintainers using an available private
GitHub contact channel. If no channel is available, request one publicly without
identifying affected people or sharing incident details. Before opening the project
to public contributions, maintainers must establish a monitored private reporting
route and identify who handles reports involving a maintainer.
