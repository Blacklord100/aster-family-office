# Optional offline document layout stage

Research checked 9 September 2026; proposal only. No Docling installation, model execution or active-benchmark change.

**Recommendation:** benchmark Docling's standard PDF layout + TableFormer pipeline as an optional shared preprocessing stage. Our current native reader is `pypdf`; PDFium renders scans for local OCR. Flattened text contributes to lost table boundaries in the NAV-table, legacy-export, consolidation and amounts-in-thousands cases. Docling detects layout regions and table rows/cells, making it a plausible structural improvement—not a demonstrated fix. Start with explicit Heron/TableFormer selections and Tesseract OCR; keep VLM conversion and optional enrichments disabled. [Model catalog](https://docling-project.github.io/docling/usage/model_catalog/)

Preserve original EML/PDF bytes, hashes, attachment ancestry and physical page numbers. Store Docling JSON alongside existing text, including available bounding boxes, table/row/cell identifiers, headers, reading order and model revisions. Its document representation supports tables, provenance and separate body/furniture layers. Do not substitute generated Markdown for original-source evidence. Adapt both workflow and agentic modes to the same versioned intermediate representation and existing candidate/review contract. [Document model](https://docling-project.github.io/docling/concepts/docling_document/)

Aster still must validate owner, reporting date, native currency and header-bound units, including deterministic `1264.5 × 1000` normalization. Separate fund totals, investor positions, checksums and revised/withdrawn observations. Docling does not supply those financial semantics. Require visual evidence links and explicit incomplete-coverage warnings when layout fails.

For offline provisioning:

1. On the connected release builder, pin package versions and model revisions; prefetch the chosen artifacts with `docling-tools models download`. Include every selected OCR language/model and configuration. Set `artifacts_path` or `DOCLING_ARTIFACTS_PATH` to the delivered directory. Default first use otherwise downloads models; changing features/languages can introduce missing artifacts. Table cell matching and FAST/ACCURATE modes require separate evaluation. [Offline/table options](https://docling-project.github.io/docling/usage/advanced_options/)
2. Explicitly set `enable_remote_services=False` and `allow_external_plugins=False`; allow only local file/byte inputs. These settings govern services/plugins, not model downloads. Enforce worker network denial, no credentials and no cloud fallback independently. [Pipeline permissions](https://docling-project.github.io/docling/reference/pipeline_options/)
3. Set `HF_HUB_OFFLINE=1`, `HF_HUB_DISABLE_TELEMETRY=1` and, if shipping the HF CLI, `HF_HUB_DISABLE_UPDATE_CHECK=1`. Hub downloads can otherwise make metadata requests even when weights are cached. These flags do not govern arbitrary third-party networking. [HF environment controls](https://huggingface.co/docs/huggingface_hub/package_reference/environment_variables)

Use an isolated worker with measured memory, thread, page and timeout limits; the current PDF subprocess's 768-MiB Linux ceiling is not a validated Docling budget. CPU execution is available; CUDA/XPU require compatible hardware/runtime builds. Layout supports MPS, but current TableFormer documentation disables MPS. Benchmark actual appliance hardware and concurrent Ollama memory pressure. [Hardware example](https://docling-project.github.io/docling/_generated/examples/run_with_accelerator/), [stage/device support](https://docling-project.github.io/docling/usage/model_catalog/)

Docling code is MIT; model weights have separate terms. Heron's card lists Apache-2.0; the aggregate docling-models card lists Apache-2.0 and CDLA-Permissive-2.0. Inspect each selected artifact's applicable license rather than treating everything as MIT. Add its source revision, hashes, licenses/notices, dependencies, OCR data, resource profile and acceptance fixtures to the signed [LP bundle](offline-lp-packaging.md). [Code license](https://github.com/docling-project/docling#license), [Heron card](https://huggingface.co/docling-project/docling-layout-heron), [model bundle card](https://huggingface.co/docling-project/docling-models)

Release only after a separate frozen comparison against existing extraction and fresh adversarial tables: exact facts/owners/units, unsupported facts, provenance, latency, peak RAM and clean-machine offline startup. Deny network access during installation, first conversion and restart; verify missing/corrupt assets fail locally. Keep the current baseline intact.
